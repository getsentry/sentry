`<MentionComposer>` adapts the shared mention editor to activity notes. It adds organization sources, Markdown preview, note serialization, and submission controls.

## Mentions as assignee selectors

Pass `assigneeSelector` with a project to render each member or team mention as the issue stream's `<AssigneeSelector>`. Clicking a mention opens the selector with that project's members and teams. Choosing someone swaps the mention, and clearing the selection removes it. The issue's assignee never changes.

<Storybook.Demo overflow="visible">
  <AssigneeSelectorMentionComposerDemo />
</Storybook.Demo>

```jsx
<MentionComposer
  mode="create"
  assigneeSelector={{project: group.project}}
  onSubmit={submitNote}
/>
```
