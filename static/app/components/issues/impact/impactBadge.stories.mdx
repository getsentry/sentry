Seer scores how much an issue affects users from 0 to 100, and buckets the score into one of five levels. The bucketing is determined from the API response, not the frontend. Each level has its own icon and color, so the level reads at a glance.

All impact UI is internal for now. Callers only render it for organizations with the `seer-impact-assessment` feature, using `useAssessedImpact(group)`.

## Badge

The activity feed uses the badge on its own, within the sentence describing the assessment.

<Storybook.Demo>
  <Stack gap="md">
    {examples.map(({level, score}) => (
      <Text key={level}>
        Impact assessed as <ImpactBadge impact={{level, score}} />
      </Text>
    ))}
  </Stack>
</Storybook.Demo>

```tsx
<ImpactBadge impact={{level: 'high', score: 73.5}} />
```

## With Hovercard

The issue details header and the universal inbox add `hovercard`. Hover a badge to see the level and Seer's description of the impact.

<Storybook.Demo>
  <Flex gap="md" wrap="wrap">
    {examples.map(example => (
      <ImpactBadge key={example.level} impact={example} hovercard />
    ))}
  </Flex>
</Storybook.Demo>

```tsx
const impact = useAssessedImpact(group);

{
  impact && <ImpactBadge impact={impact} hovercard />;
}
```
