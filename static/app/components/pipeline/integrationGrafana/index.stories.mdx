The registered Grafana pipeline collects a stack URL and service account token. The backend validates the connection before completing installation, so failed checks can be corrected in the same form.

## Credentials

This demo renders the credentials step without making API requests. Use synthetic credentials.

## Accessibility

Both fields have associated labels and help text. The token is masked, and the Continue button is disabled while initialization or submission is pending. The pipeline modal announces connection failures with an alert.
