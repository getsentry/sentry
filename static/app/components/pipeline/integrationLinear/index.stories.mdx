The Linear pipeline opens an authorization popup for the Sentry app. A Linear workspace admin approves read and write access for the organization. Sentry checks workspace access before completing installation and renews tokens automatically for background investigations. Seer reaches Linear through its read-only MCP endpoint.

## Authorization

This demo renders the authorization step with its button disabled. It does not open a popup or make API requests.

## Accessibility

The authorization button has an accessible label and is disabled until the authorization URL is ready. Cancellation and connection failures are announced with alerts. If the browser blocks the popup, the step explains how to retry.
