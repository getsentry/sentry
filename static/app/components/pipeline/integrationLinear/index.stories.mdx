The registered Linear pipeline collects a personal API key. The backend checks that the key can read its Linear workspace before completing installation, so a rejected key can be corrected in the same form. Seer reaches Linear through its read-only MCP endpoint.

## Credentials

This demo renders the credentials step without making API requests. Use a synthetic key.

## Accessibility

The API key field has an associated label and help text. The key is masked, and the Continue button is disabled while initialization or submission is pending. The pipeline modal announces connection failures with an alert.
