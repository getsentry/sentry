The Supabase pipeline opens an authorization popup to connect a Supabase organization. A Supabase organization owner authorizes the read-only connection, which lets Seer read project logs and current infrastructure and database metrics and is shared with the Sentry organization.

## Authorization

This demo disables authorization until the backend supplies an OAuth URL. It does not open a popup or make API requests.

## Props

The pipeline provides the standard `PipelineStepProps`. The authorization step uses these props:

| Prop          | Type                                             | Description                                                   |
| ------------- | ------------------------------------------------ | ------------------------------------------------------------- |
| `stepData`    | `{oauthUrl?: string} \| null`                    | Authorization URL supplied by the backend.                    |
| `advance`     | `(data?: {code: string; state: string}) => void` | Submits the authorization callback to the pipeline.           |
| `isAdvancing` | `boolean`                                        | Disables authorization while the callback is being submitted. |

## Accessibility

The authorization button has an accessible label and is disabled until the authorization URL is ready. Cancellation and connection failures are announced with alerts. If the browser blocks the popup, the step explains how to retry.
