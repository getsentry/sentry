`RelativeTime` is the hover detail for a timestamp rendered elsewhere. Sentry surfaces
timestamps as relative strings — "43min ago", "8 months ago" — which are quick to scan but
ambiguous when you are debugging across timezones. This card resolves that ambiguity by
showing the absolute time twice: once in the viewer's timezone and once in UTC.

<Storybook.Demo>
  <RelativeTime date="2026-07-29T06:40:00Z" label="Last Seen" suffix="ago" />
</Storybook.Demo>

## Usage

This is tooltip content, not a standalone element. It is designed to fill a tooltip edge to
edge, so it needs the tooltip's own padding removed and its centered text alignment reset.
`RELATIVE_TIME_TOOLTIP_PROPS` carries both, plus the width the card is designed at.

```jsx
import {RELATIVE_TIME_TOOLTIP_PROPS, RelativeTime} from '@sentry/scraps/relativeTime';

<TimeSince
  date={date}
  suffix="ago"
  unitStyle="short"
  {...RELATIVE_TIME_TOOLTIP_PROPS}
  tooltipBody={
    <RelativeTime date={date} label={t('Last Seen')} suffix="ago" unitStyle="short" />
  }
/>;
```

Pass `tooltipBody` rather than `tooltipPrefix` — the card renders its own label, and a
`tooltipPrefix` would stack a second one above it.

## Matching the trigger

The header repeats the relative time so the card reads as an expansion of what was hovered
rather than a separate fact. For that to hold, give `RelativeTime` the same `unitStyle`,
`suffix`, and `prefix` as the trigger. A trigger reading "43min ago" should open a card whose
header also reads "43min ago", not "43 minutes ago".

<Storybook.Demo>
  <RelativeTime
    date="2026-07-29T06:40:00Z"
    label="Last Seen"
    suffix="ago"
    unitStyle="short"
  />
</Storybook.Demo>

## Timezones

The first row follows the viewer's timezone, taken from `useTimezone()` — the user's
configured timezone, falling back to the browser's. The second row is always UTC. The
abbreviation in each badge is derived from the date itself, so it reflects daylight saving at
that moment rather than today: a July timestamp shows `PDT` even when read in December.

Both rows honor the viewer's 24-hour clock preference.

## Marker

The header can carry an accent dot before the label via `showMarker`. It is off by default:
the dot reads as a status signal, so it should only appear where it means something rather
than as decoration.

</Storybook.Demo>
