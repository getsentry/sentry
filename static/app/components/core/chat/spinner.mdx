The `Spinner` is a small circular activity indicator for agent conversation
surfaces — shown next to a message that is streaming or a tool call that is
still running. For full-width, indeterminate progress use the
[`IndeterminateLoader`](?name=IndeterminateLoader) instead.

## Accessibility

The spinner is decorative by default (`aria-hidden`) — reach for that when
adjacent text already communicates that work is in progress. When the spinner
is the only signal, pass an `aria-label` (and `role="status"`) so screen
readers announce it.

```jsx
// Decorative — the label already says what is happening
<Flex align="center" gap="sm">
  <Spinner />
  <Text>Running…</Text>
</Flex>

// Meaningful — the spinner is the only signal
<Spinner role="status" aria-label="Loading" />
```

When the user prefers reduced motion, the spinner slows to a gentle rotation.
