import {ToolCallIndicator} from '@sentry/scraps/chat';
import {Text} from '@sentry/scraps/text';

import * as Storybook from 'sentry/stories';

export const documentation =
  import('!!type-loader!@sentry/scraps/chat/toolCallIndicator');

The `ToolCallIndicator` communicates the aggregate status of a message's tool
calls in an agent conversation: a spinner while they run and a semantic icon
once they settle.

## Statuses

<Storybook.Demo>
  <Grid columns="16px 1fr" flow="row" gap="md" align="center">
    <ToolCallIndicator status="loading" />
    <Text>loading — work in progress</Text>

    <ToolCallIndicator status="pending" />
    <Text>pending — waiting for approval</Text>

    <ToolCallIndicator status="success" />
    <Text>success — all tool calls succeeded</Text>

    <ToolCallIndicator status="mixed" />
    <Text>mixed — some succeeded, some failed</Text>

    <ToolCallIndicator status="failure" />
    <Text>failure — all tool calls failed</Text>

  </Grid>
</Storybook.Demo>

```jsx
<ToolCallIndicator status="loading" />
<ToolCallIndicator status="pending" />
<ToolCallIndicator status="success" />
<ToolCallIndicator status="mixed" />
<ToolCallIndicator status="failure" />
```

The `content` status (a message with no tool calls, only content) renders
nothing, so it is safe to pass a status derived from any message.

## Labels

Each status carries a default tooltip and accessible label. Override it with the
`label` prop when the surrounding context needs more specific wording.

<Storybook.Demo>
  <Flex align="center" gap="sm">
    <ToolCallIndicator status="failure" label="Search returned no results" />
    <Text variant="muted">Custom label</Text>
  </Flex>
</Storybook.Demo>

```jsx
<ToolCallIndicator status="failure" label="Search returned no results" />
```
