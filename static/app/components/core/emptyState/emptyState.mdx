`EmptyState` is a composable layout for "nothing to show" states. It supports an optional illustration, description, and action slot, in both vertical and horizontal orientations.

## Vertical (default)

The default orientation stacks elements in a centered column.

<Storybook.Demo>
  <EmptyState
    title="No issues match your search."
    description="Try widening your search or adjusting your filters."
  />
</Storybook.Demo>
```jsx
<EmptyState
  title="No issues match your search."
  description="Try widening your search or adjusting your filters."
/>
```

## Title Only

The simplest empty state — just a title, no description or action.

  <EmptyState title="No results." />
</Storybook.Demo>
```jsx

```

## When to Use

- **No results**: A search or filter returned zero matches
- **No data**: A feature area has no data to display yet
- **First-time setup**: A feature requires configuration before use (use with illustration and CTA)

Prefer `EmptyState` over building custom empty UIs with ad-hoc styled components.
