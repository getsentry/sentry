`EmptyState` is a composable layout for "nothing to show" states. It supports an optional illustration, description, and action slot. Layout is responsive — stacked vertically in narrow containers, side-by-side in wide ones. Drag the resize handle to see it switch.

## When to Use

- **No results**: A search or filter returned zero matches
- **No data**: A feature area has no data to display yet
- **First-time setup**: A feature requires configuration before use (use with illustration and CTA)

Prefer `EmptyState` over building custom empty UIs with ad-hoc styled components.
