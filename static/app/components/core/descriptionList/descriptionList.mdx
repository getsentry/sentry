`DescriptionList` renders a semantic `<dl>` as a two-column grid: terms size to their content, and details take the remaining space.
Compose it with `DescriptionList.Term` and `DescriptionList.Details`, one pair per row.

```jsx
<DescriptionList>
  <DescriptionList.Term>Occurred</DescriptionList.Term>
  <DescriptionList.Details>Jan 1, 2026 12:00:00 PM UTC</DescriptionList.Details>
</DescriptionList>
```

## When to use

Use `DescriptionList` for short, panel-free key/value pairs, such as the details in a tooltip or a sidebar.
By default it has no borders, backgrounds, or row striping, so it adapts to whatever surface it sits on.
For a list that spans the width of a sidebar or panel, use the [striped](#striped) treatment.

> [!NOTE]
> For event data in a bordered card, use `KeyValueTableCard` from `sentry/components/tables/keyValueTable` instead.
> gsAdmin's `DetailList` builds its wide-label layout on top of this component.

## Basic Usage

Terms are muted so the details stand out. Details break anywhere when they would otherwise overflow, so long identifiers and URLs stay inside the list.

## Gap

The `gap` prop sets the row and column gap, and accepts the same responsive space tokens as `Grid`. It defaults to `sm md`.

<Storybook.Demo>

    <DescriptionList.Details>String</DescriptionList.Details>
    <DescriptionList.Term>Kind</DescriptionList.Term>
    <DescriptionList.Details>Tag</DescriptionList.Details>
  </DescriptionList>
</Storybook.Demo>

```jsx
<DescriptionList gap="xs">

  <DescriptionList.Details>Tag</DescriptionList.Details>

```

## Striped

The `striped` prop lays the list out as a full-width table: alternate rows are striped, terms and details split the width evenly, and details sit against the far edge.
Each cell stays on one line and truncates, so keep details short.

<Storybook.Demo>
  <DescriptionList striped>
    <DescriptionList.Term>Date created</DescriptionList.Term>
    <DescriptionList.Details>Jan 1, 2026</DescriptionList.Details>
    <DescriptionList.Term>Created by</DescriptionList.Term>
    <DescriptionList.Details>user@example.com</DescriptionList.Details>
    <DescriptionList.Term>Last modified</DescriptionList.Term>
    <DescriptionList.Details>2 hours ago</DescriptionList.Details>
  </DescriptionList>
</Storybook.Demo>

## Accessibility

`DescriptionList` uses native `<dl>`, `<dt>`, and `<dd>` elements, so assistive technology announces each term with its details (WCAG 1.3.1).

### Developer responsibilities

- Only place `DescriptionList.Term` and `DescriptionList.Details` directly inside a `DescriptionList`. Wrapping a pair in a `Fragment` is fine; wrapping it in a `div` breaks the grid.
- Give every `DescriptionList.Term` at least one `DescriptionList.Details`.
