export const documentation = import('!!type-loader!@sentry/scraps/menu');

Use `Menu` when the content needs custom structure. The pieces are composed directly in JSX. `Menu.List` contains the menu items; `Menu.Header` and `Menu.Footer` stay outside its scrolling area. `Menu.Search` filters items by their string `label`, or by `textValue` when the label is custom content.

`DropdownMenu` and `CompactSelect` continue to support their existing array APIs.
