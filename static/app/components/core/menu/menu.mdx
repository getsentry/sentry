`Menu` contains the visual parts shared by `DropdownMenu` and `CompactSelect`. It has no menu context or collection state. Those controls supply the overlay, selection, keyboard behavior, and accessibility roles. Use them for application interactions.

## Composition

This preview shows how the parts fit together. It does not implement menu or select behavior.

## Accessibility

`Menu` provides presentation only. A control that composes these parts must supply its own roles, labels, focus management, and keyboard behavior.
