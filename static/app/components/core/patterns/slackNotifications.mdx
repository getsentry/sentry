Sentry sends Slack notifications as [Block Kit](https://docs.slack.dev/reference/block-kit/) JSON. The examples on this page show what those payloads look like. Copy the JSON, or open it in Slack's [Block Kit Builder](https://app.slack.com/block-kit-builder/) to see how it renders and try your own changes.

## Alert triggered

Sent when an alert fires for a new issue. This example is for a User Feedback issue.

## Formatting tips

- **Links** use Slack's `<url|label>` syntax, not Markdown's `[label](url)`.
- **Bold** text uses single asterisks (`*bold*`), not double.
- **`block_id`** must be a string, so Sentry stores structured data like `{"issue":123,"workflow":456}` as escaped JSON.
