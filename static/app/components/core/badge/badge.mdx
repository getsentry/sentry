Badges are highlighted text components that support specific use cases like
`ProjectsBadge`, `AlertBadge`, and `DeployBadge`.

See [FeatureBadge](/scraps/core/featurebadge/) for feature rollout stages and
[Tag](/scraps/core/tag/) for generic status indicators.

## ProjectsBadge

`ProjectsBadge` renders a fixed 16×16 badge of the project platform icons. It's used
by secondary-navigation items and breadcrumb crumbs to give each a recognizable glyph
while keeping every leading slot the same size.

The badge adapts to how many platform slugs you pass in `projectPlatforms`:

- **0 platforms** — a "my projects" glyph, or an "all projects" glyph when `allProjects`
  is set.
- **1 platform** — a single bordered platform icon.
- **2+ platforms** — the first two platforms as stacked icons (extra platforms are not
  shown).

<Storybook.Grid>
  <Flex align="center" gap="sm">
    <ProjectsBadge projectPlatforms={[]} />
    <Text variant="muted">My projects (0)</Text>
  </Flex>
  <Flex align="center" gap="sm">
    <ProjectsBadge projectPlatforms={[]} allProjects />
    <Text variant="muted">All projects (0)</Text>
  </Flex>
  <Flex align="center" gap="sm">
    <ProjectsBadge projectPlatforms={['javascript']} />
    <Text variant="muted">1 platform</Text>
  </Flex>
  <Flex align="center" gap="sm">
    <ProjectsBadge projectPlatforms={['python', 'javascript']} />
    <Text variant="muted">2 platforms</Text>
  </Flex>
  <Flex align="center" gap="sm">
    <ProjectsBadge projectPlatforms={['react', 'node', 'python']} />
    <Text variant="muted">3 platforms (first two shown)</Text>
  </Flex>
</Storybook.Grid>
```tsx
{/* No projects selected */}
<ProjectsBadge projectPlatforms={[]} />
{/* All projects */}
<ProjectsBadge projectPlatforms={[]} allProjects />
{/* A single project */}
<ProjectsBadge projectPlatforms={['javascript']} />
{/* Multiple projects — first two platforms are stacked */}
<ProjectsBadge projectPlatforms={['python', 'javascript']} />
```

Platform slugs are passed straight through to `PlatformIcon` from `platformicons`, so any
supported platform renders:

<Storybook.Grid>
  {['javascript', 'python', 'ruby', 'php', 'java', 'go', 'rust', 'node'].map(platform => (
    <Flex key={platform} align="center" gap="sm">
      <ProjectsBadge projectPlatforms={[platform]} />
      <Text variant="muted">{platform}</Text>
    </Flex>
  ))}
</Storybook.Grid>

### Accessibility

The badge renders `aria-hidden` — it's decorative, and its meaning is carried by the label
it sits beside.

### Developer responsibilities

- Always pair `ProjectsBadge` with a visible text label. Never rely on the badge alone to
  convey which saved view, project, or item a crumb or link points to.

## AlertBadge

The `AlertBadge` component displays an indicator for all Alert types that Sentry supports.

- For metric alerts, set the `status` prop to the `IncidentStatus` enum (from `sentry/views/alerts/types`).

<Storybook.Demo>
  <AlertBadge status={IncidentStatus.OPENED} />
  <AlertBadge status={IncidentStatus.CLOSED} />
  <AlertBadge status={IncidentStatus.WARNING} />
  <AlertBadge status={IncidentStatus.CRITICAL} />
</Storybook.Demo>
```jsx import {AlertBadge} from '@sentry/scraps/badge';

<AlertBadge status={IncidentStatus.OPENED} />
<AlertBadge status={IncidentStatus.CLOSED} />
<AlertBadge status={IncidentStatus.WARNING} />
<AlertBadge status={IncidentStatus.CRITICAL} />
```

## DeployBadge

export const deploy = {
  name: '85fedddce5a61a58b160fa6b3d6a1a8451e94eb9 to prod',
  url: '',

  dateStarted: '2020-05-11T18:12:00.025928Z',
  dateFinished: '2020-05-11T18:12:00.025928Z',
  version: '4.2.0',
  id: '6348842',
};

The `DeployBadge` component can be used to link to the Issues feed, filtered to issues related to a specific release.

The text of each badge is derived from the `environment` passed to the `deploy` property, which must adhere to `import type {Deploy} from 'sentry/types/release'`.

