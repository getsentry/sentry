The `EvidenceReference` renders a reference to something Seer looked at — a
trace, an issue, a search, a doc — iconed and labeled the same way everywhere
it shows up. The `type` → icon (and, for the `button` variant, label prefix)
mapping is the Telemetry Icons board, kept in one place so a trace looks like
a trace whether it is a Code Mode call's destination chip, a markdown embed,
or an autofix evidence link.

## Variants

`variant: 'button'` renders a standalone chip — `Icon Type: value` — for a
call-to-action like a `ToolCall` reference (see
[ToolCall's Resource icons](/stories/core/toolcall/#resource-icons)).
`variant: 'link'` renders a plain inline anchor — `Icon value`, no type prefix
— for prose contexts like a seer markdown embed.

## Icons

Every `type` the Telemetry Icons board defines. Import `EVIDENCE_ICON` when
you need the icon component alone — for instance to build a custom reference
chip (see `ToolCall`'s `reference` prop) rather than rendering
`EvidenceReference` itself.

## Interactivity

The `button` variant renders a real anchor when given `to` (so middle/cmd-click
and keyboard access work), an interactive button when given only `onClick`, or
a non-interactive display chip when given neither.

<Storybook.Demo>
  <Flex gap="lg" wrap="wrap" align="center">
    <EvidenceReference variant="button" type="issue" value="SEER-123" to="/issues/123/" />
    <EvidenceReference
      variant="button"
      type="issue"
      value="SEER-123"
      onClick={() => {}}
    />
    <EvidenceReference variant="button" type="issue" value="SEER-123" />
  </Flex>
</Storybook.Demo>

```jsx
<EvidenceReference variant="button" type="issue" value="SEER-123" to="/issues/123/" />
<EvidenceReference variant="button" type="issue" value="SEER-123" onClick={() => trackClick()} />
<EvidenceReference variant="button" type="issue" value="SEER-123" />
```

The `link` variant only ever renders an anchor, and only for a safe `href`: an
`http(s)://` URL, or a path starting with a single `/`. Anything else (an
unsafe scheme, a bare word) renders nothing — a dropped link beats a dead or
unsafe one.
