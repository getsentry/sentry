import {InvitationStatus} from 'sentry/views/authV2/acceptOrganizationInvite/invitationStatus';
import * as Storybook from 'sentry/stories';

`getInvitationStep` selects the next step from invitation details. `InvitationStatus` renders acceptance, account switching, SSO guidance, two-factor setup, or refresh progress. The page owns mutations and renders account authentication separately.

## Props

| Prop              | Type                                                              | Description                             |
| ----------------- | ----------------------------------------------------------------- | --------------------------------------- |
| `step`            | `Exclude<ReturnType<typeof getInvitationStep>, 'authentication'>` | The current invitation status.          |
| `isAccepting`     | `boolean`                                                         | Disables acceptance while submitting.   |
| `onAccept`        | `() => void`                                                      | Submits invitation acceptance.          |
| `onSwitchAccount` | `() => void`                                                      | Starts the parent-owned account switch. |

## Accessibility

Status guidance is rendered as text, and the next actions use labeled buttons or links. Two-factor setup opens account security in a new tab so the invitation stays available.
