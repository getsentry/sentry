import {InvitationAccountBadge} from 'sentry/views/authV2/acceptOrganizationInvite/invitationAccountBadge';
import * as Storybook from 'sentry/stories';

Show the signed-in account alongside an invitation so users can confirm which account will join the organization. The parent owns logout and invitation refetching.

## Signed-In Account

<Storybook.Demo>
  <InvitationAccountBadge
    user={{
      id: '1',
      name: 'Jane Doe',
      email: 'jane@example.com',
      username: 'jane@example.com',
      ip_address: '127.0.0.1',
    }}
    onSwitchAccount={() => {}}
  />
</Storybook.Demo>

```tsx
<InvitationAccountBadge user={user} onSwitchAccount={switchAccount} />
```

## Props

| Prop              | Type         | Description                             |
| ----------------- | ------------ | --------------------------------------- |
| `user`            | `AvatarUser` | The account accepting the invitation.   |
| `onSwitchAccount` | `() => void` | Starts the parent-owned account switch. |

## Accessibility

The account name and email identify the user in text. The labeled switch button supports keyboard navigation.
