import {OrganizationConsentCard} from './organizationConsentCard';
import * as Storybook from 'sentry/stories';

The organization card displays the selected organization and a change menu with organization badges. The orchestration view owns the section heading and form, and uses `useOAuthOrganization` to select the last active eligible organization or the first available organization. Selection is scoped to the prepared consent session.
