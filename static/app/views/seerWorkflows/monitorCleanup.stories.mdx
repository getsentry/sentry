import {MonitorCleanupResults} from 'sentry/views/seerWorkflows/monitorCleanup';
import * as Storybook from 'sentry/stories';

The workflow history renders typed monitor findings here. Monitor links open the existing
monitor details page. Exact duplicate findings suggest a keeper, with a disabled deletion button for this demo.
Cards show linked monitors and a short explanation. View comparison opens a property
table with one column per monitor and differing values marked. Narrative reports are omitted. Notification findings link to connected alerts.
The scan summary aggregates inspected monitors across projects; incomplete runs say so.
