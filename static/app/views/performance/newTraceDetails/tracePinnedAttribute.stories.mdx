The standalone EAP trace waterfall can show one pinned span attribute. Its tree,
attribute, and timeline columns share vertical scrolling, while their horizontal
positions remain independent. Replay and Seer embeds do not support pinning.

The `trace-waterfall-attribute-pinning` organization feature enables the pinned column
and attribute request. Use “Pin to waterfall” or “Unpin from waterfall” in the
attribute's `…` menu in the drawer. Registration and rollout live in separate PRs.

## Header and request failure

The header names the attribute and offers an unpin action. A failed attribute
request exposes retry without replacing the trace or changing selection or zoom.

export function HeaderExample() {
  const [attribute, setAttribute] = useState('custom.region');
  const [isError, setIsError] = useState(false);
  return (
    <TracePinnedAttributeContext
      value={{
        enabled: true,
        attribute,
        setAttribute,
        isError,
        isPending: false,
        retry: () => setIsError(false),
        values: new Map(),
      }}
    >
      <Flex direction="column" gap="md">
        <Flex width="240px" minHeight="38px" border="primary">
          <TracePinnedAttributeHeader />
        </Flex>
        <Flex gap="md">
          <Button size="sm" onClick={() => setAttribute('custom.region')}>
            Pin attribute
          </Button>
          <Button size="sm" onClick={() => setIsError(true)}>
            Simulate request failure
          </Button>
        </Flex>
      </Flex>
    </TracePinnedAttributeContext>
  );
}

## Column behavior

- Drag either separator to exchange width with its adjacent column. Arrow keys move
  the separator by 10px; Shift plus an arrow moves it by 50px.
- The attribute starts at 200px. Minimum tree, attribute, and timeline widths are
  120px, 100px, and 100px. Narrow layouts temporarily shrink the attribute before
  allowing horizontal overflow, then restore its preferred width.
- Pinning and unpinning allocate space proportionally. Width preferences remain
  in browser storage. The pinned attribute lives in the URL using history replacement.
- Auto-grouped rows show `—`. Collapsed span groups show their common value,
  “Multiple values” when members differ, or `—` when all members lack the attribute.
  Ordinary parent spans keep their own value.
- Values remain on one line with ellipsis and a copy action on hover/focus.
  Clicking a value selects its span.

## Integration

`useTracePinnedAttribute` owns the URL and attribute query. Its context surrounds
both the drawer and waterfall. Attribute responses are indexed by span ID without
replacing the trace tree. `VirtualizedViewManager` owns the three column widths and
recalculates timeline coordinates when the right separator moves.
