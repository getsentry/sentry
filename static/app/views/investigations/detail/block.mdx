`InvestigationNotebookBlock` renders one block of an investigation notebook: its text or
query output, the progress of its Seer run, an actions menu, and a comment button.

```jsx
<InvestigationNotebookBlock
  block={block}
  canRun={investigation.status === 'active'}
  investigation={investigation}
  commentCount={commentCounts?.[block.id]}
  onComment={openBlockComments}
/>
```

## When to use

Use it only to render blocks in the investigation notebook. It is not a general-purpose
card.

**Do**

- Pass the full `investigation` from the detail query. The waiting and blocked states read
  the block's dependencies from `investigation.blocks`.
- Filter blocks with `shouldDisplayInvestigationBlock` before rendering them, like the
  notebook does. Queued blocks with nothing to show stay hidden.
- Set `canRun` to whether the investigation is active. When it is `false`, Delete is
  disabled. Delete is also disabled while a run is in progress.
- Pass `onComment` only when the comments drawer can open. Without it, the comment button
  and the Comment menu item are hidden.
- Pass `commentCount` so blocks with comments keep the comment button visible. Without
  comments, it only appears on hover.
- Put query results in `output.tableMarkdown`. A short sentence above or below the table
  is fine.
- In stories and tests, set `currentExecution` as well as `outputStatus`. Progress and
  failure alerts read the execution status.

**Don't**

- Don't render it outside an investigation. It loads data through the investigations API,
  registers the block as Seer context, and polls a running text block every 500 ms.
- Don't use it as a generic card or collapsible section. Use `Container`, `Stack`, or
  `Disclosure` from `@sentry/scraps` instead.

## Pre-run and terminal states

export function PreRunExample() {
  return (
    <InvestigationFixtureApi
      organizationSlug="storybook-investigation-block-pre-run"
      details={[preRunInvestigation]}
    >
      <Stack gap="2xl">
        {[notRunBlock, availableBlock, restrictedBlock, waitingBlock, completedBlock].map(
          block => (
            <InvestigationNotebookBlock
              key={block.id}
              block={block}
              canRun={block.id !== restrictedBlock.id}
              investigation={preRunInvestigation}
            />
          )
        )}
      </Stack>
    </InvestigationFixtureApi>
  );
}

Not run, available, restricted, waiting for an auto-run dependency, and completed.
