import {Button} from '@sentry/scraps/button';

import {SeerOutOfCreditsCta} from 'getsentry/components/ai/seerOutOfCreditsCta';
import {SeerOutOfCreditsNotice} from 'getsentry/components/ai/seerOutOfCreditsNotice';

Product code renders `SeerOutOfCreditsCta` with the surface the org can't
afford, and getsentry fills it in: the copy depends on the surface, whether the
viewer has billing access, and whether auto-reload is already on. Open source has
no credits and renders nothing. These demos render the `SeerOutOfCreditsNotice`
underneath it. The copy and buttons follow the Billing Gates designs in Figma.

```jsx
<SeerOutOfCreditsCta reason="agent-chat" />
<SeerOutOfCreditsCta reason="autofix-start" variant="muted" />
```

## Agent chat

Shown above the chat composer when the org can't afford another message.
Billing members turn on auto-reload in place, in the billing page's
auto-reload modal. The chat uses full-size buttons; Autofix uses small ones.

<Storybook.Demo>
  <SeerOutOfCreditsNotice
    reason="agent-chat"
    escalation="configure"
    onConfigureAutoReload={() => {}}
  />
</Storybook.Demo>

```jsx
<SeerOutOfCreditsNotice
  reason="agent-chat"
  escalation="configure"
  onConfigureAutoReload={openAutoReloadModal}
/>
```

## Members

Members email their admins with "Contact Admin". Sending shows an "Admins
emailed." toast, and the button then reads "Admins emailed" until the billing
period ends.

<Storybook.Demo>
  <Stack gap="md" width="100%">
    <SeerOutOfCreditsNotice
      reason="agent-chat"
      escalation="request"
      onRequestCredits={() => {}}
    />
    <SeerOutOfCreditsNotice
      reason="agent-chat"
      escalation="request"
      onRequestCredits={() => {}}
      isRequestingCredits
    />
    <SeerOutOfCreditsNotice
      reason="agent-chat"
      escalation="request"
      onRequestCredits={() => {}}

## For the signed-in viewer

`SeerOutOfCreditsCta` itself, with the escalation and copy it picks for you.
The auto-reload button and "Contact Admin" do the real thing: the modal reads and
saves your org's Seer wallet, and "Contact Admin" emails your billing members.
