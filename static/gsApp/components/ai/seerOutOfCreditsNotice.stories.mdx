import {Button} from '@sentry/scraps/button';
import {Stack} from '@sentry/scraps/layout';

import * as Storybook from 'sentry/stories';

import {SeerOutOfCreditsNotice} from 'getsentry/components/ai/seerOutOfCreditsNotice';

Product code renders `SeerOutOfCreditsCta` with the surface the org can't
afford, and getsentry fills it in: the copy depends on the surface, whether the
viewer has billing access, and whether auto reload is already on. Open source has
no credits and renders nothing. These demos render the `SeerOutOfCreditsNotice`
underneath it. The copy comes from the "Seer Billing Gates Copy" spec.

```jsx
<SeerOutOfCreditsCta reason="agent-chat" />
<SeerOutOfCreditsCta reason="autofix-start" variant="muted" />
```

## Members

The spec has no member copy yet. Members get the first sentence of the billing
copy plus who to ask, and ask the billing members for credits. Sending the
request shows a toast, and the button then reads "Request sent" until the billing
period ends.

<Storybook.Demo>
  <Stack gap="md" width="100%">
    <SeerOutOfCreditsNotice
      reason="agent-chat"
      escalation="request"
      onRequestCredits={() => {}}
    />
    <SeerOutOfCreditsNotice
      reason="agent-chat"
      escalation="request"
      onRequestCredits={() => {}}
      isRequestingCredits
    />
    <SeerOutOfCreditsNotice
      reason="agent-chat"
      escalation="request"
      onRequestCredits={() => {}}
      hasRequestedCredits
    />
  </Stack>
</Storybook.Demo>

```jsx
<SeerOutOfCreditsNotice reason="agent-chat" escalation="request" onRequestCredits={handleRequestCredits} />
<SeerOutOfCreditsNotice reason="agent-chat" escalation="request" onRequestCredits={handleRequestCredits} isRequestingCredits />
<SeerOutOfCreditsNotice reason="agent-chat" escalation="request" onRequestCredits={handleRequestCredits} hasRequestedCredits />
```
